# 🛒 Lista de Compras

Aplicação web simples e intuitiva para gerenciamento de listas de compras, permitindo ao usuário adicionar, remover e organizar itens de forma prática e eficiente.

---

## 📌 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de facilitar o controle de compras do dia a dia, substituindo listas manuais por uma solução digital acessível via navegador.

---

## 🚀 Funcionalidades

- ✅ Adicionar itens à lista  
- ❌ Remover itens  
- 📋 Visualizar lista em tempo real  
- 🧹 Interface simples e intuitiva  
- 💻 Acesso direto pelo navegador (sem instalação)
